# Revit Auto Sheet View

Add-in cho **Autodesk Revit 2022 – 2027**: tự động tạo sheet và view (mặt bằng, mặt bằng trần, mặt đứng nội thất, 3D) cho các phòng và dàn trang lên sheet.

Repo này chỉ chứa **file cài đặt**. Mã nguồn được quản lý riêng.

## Tải về

👉 **[Tải bản mới nhất](../../releases/latest)**

| File | Dùng khi |
|---|---|
| **`…-Setup.exe`** | **Khuyên dùng.** Bộ cài có giao diện: tự nhận Revit trên máy, bấm *Cài đặt* là xong. |
| `…-SingleUser.msi` | Cho IT / cài im lặng, chỉ tài khoản hiện tại, không cần Admin. |
| `…-MultiUser.msi` | Cho IT / cài im lặng, mọi tài khoản trên máy, cần Admin. |
| `HUONG_DAN_CAI_DAT.txt` | Hướng dẫn cài đặt chi tiết. |

## Cài đặt nhanh

1. Đóng Revit.
2. Tải và chạy **`Revit_Auto_Sheet_View-…-Setup.exe`**. Nếu Windows hiện *"Windows protected your PC"*: bấm **More info → Run anyway**.
3. Các phiên bản Revit có trên máy đã được chọn sẵn → **Cài đặt** → **Hoàn tất**.
4. Mở Revit → tab **Auto Sheet View** → nút **License** → dán license key → **Room Sheet Batch**.

## Cập nhật

Từ phiên bản **1.1.0**, add-in **tự kiểm tra bản mới** khi mở Revit. Bấm **Cập nhật** → bản mới tự cài khi bạn đóng Revit, không cần tải lại file `.msi`.
